# Écru Bageri

## Om projektet
Écru Bageri är ett fiktivt nordiskt hantverksbageri.
Projektet består av en responsiv webbplats.

## Webbplatsens innehåll

Webbplatsen består av tre sidor:

- **Startsida** – Presenterarar bageriet.
- **Sortiment** – Visar urval ett av bageriets produkter.
- **Om oss** – Visar bakningsprocessen och kontaktuppgifter.

## Tekniker

Projektet använder:
- HTML
- CSS
- JavaScript
